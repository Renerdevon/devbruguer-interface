# 🍔 DevBurger — Frontend

Interface web de uma aplicação full stack para gestão de pedidos de uma hamburgueria.

Projeto desenvolvido com foco em **componentização**, **experiência do usuário** e **integração com API**.  
Este repositório representa a camada de **frontend** do sistema.

---

## 🖥️ Funcionalidades

- Listagem de produtos e categorias
- Carrinho de compras
- Autenticação de usuário
- Área administrativa
- Interface responsiva

---

## 🛠 Tecnologias Utilizadas

- React
- Vite
- Styled Components
- React Router
- Axios
